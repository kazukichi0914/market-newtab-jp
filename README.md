# マーケット新規タブ（Chrome 拡張）v2

Chrome の新規タブを、日本の個人投資家向けの金融ダッシュボードに置き換えます。
設計の詳細は [docs/DESIGN.md](docs/DESIGN.md) を参照してください。

## 表示内容

| パネル | 内容 |
|---|---|
| ヘッダー | 日本時間の時計、東京（前場/昼休み/後場/休場）・先物（日中/夜間）・ロンドン・NY の開閉状況（祝日・夏時間・短縮取引に対応。マウスを乗せると開始/終了までの時間）、検索（銘柄名・コードのサジェスト付き） |
| 国内指数 | 日経平均、TOPIX、日経225先物（CME）、グロース250、JPX日経400、東証REIT指数 |
| 為替 | ドル円・ユーロ円・ポンド円・豪ドル円・人民元円・ユーロドル |
| 海外指数 | NYダウ、S&P500、NASDAQ、SOX、全世界株（ACWI）、ハンセン、上海総合、DAX |
| 金利・商品・暗号資産 | 日本10年国債利回り（財務省）、米10年債、VIX、WTI、金（ドル建・円換算）、ビットコイン |
| ウォッチリスト | 最大5リスト×50銘柄。ヒートマップ、出来高、52週レンジ。ドラッグで並べ替え、列ソート、CSV 入出力 |
| 今日の予定 | 7日以内の日銀会合・FOMC・SQ・東証/米国の休場日 |
| ポートフォリオ | 保有の評価額・評価損益・本日の損益、口座区分（特定/一般/NISA）別・銘柄別の構成比。金額を隠すボタン |
| 経済ニュース | Yahoo!ニュース（経済）・NHK の RSS（見出しとリンクのみ） |

- 期間切替：1日 / 5日 / 1ヶ月 / 6ヶ月 / 1年 / 5年
- 設定：騰落色（日本式=赤上昇 / 海外式）、テーマ（OS/ライト/ダーク）、更新間隔（市場時間中・時間外を別々に）、情報密度、検索エンジン、パネルの表示/非表示と並び順
- ショートカット：`/` 検索、`r` 更新、`1`〜`6` 期間、`h` 金額の表示切替

## 仕組み（v1 からの変更点）

外部への通信は **Service Worker（`background.js`）だけ** が行い、結果を `chrome.storage.local` に保存します。
新規タブは保存済みのデータを即座に表示するだけなので、タブを何枚開いても通信は増えません。
更新は `chrome.alarms` で行い、市場が開いている間は設定の間隔（既定1分）、閉まっている間は15分ごとです。閉場中の銘柄は30分に1回しか取りに行きません。

v1 のウォッチリストと設定は、更新時に自動で引き継がれます。

## インストール

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパー モード」をオン
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダ（`新規タブ株情報`）を選択
   （v1 を読み込み済みの場合は、拡張機能ページで再読み込み ⟳ を押すだけで v2 に更新されます）
4. 新しいタブを開く（初回は「この変更を維持しますか？」と聞かれるので「変更を維持」）

Chrome 120 以降が必要です。

## 開発

ビルドは不要です（ES Modules をそのまま読み込みます）。テストには Node.js 20 以降を使います。

```bash
npm test
```

```bash
npm run smoke
```

```bash
npm run sim
```

- `npm test`：単体テスト（市場カレンダー、銘柄の正規化、データ解析、ポートフォリオ計算、設定の移行など）
- `npm run smoke`：実際の取得元（Yahoo Finance・財務省・RSS）に接続して形式を確認
- `npm run sim`：`chrome.*` API を疑似的に用意して `background.js` を Node 上で動かし、移行→取得→保存→メッセージ応答までを確認

拡張の外で画面だけ確認するときは、開発用サーバーを起動して `?mock` 付きで開きます（ダミーデータで表示。保存先も本番とは別）。

```bash
python3 tools/devserver.py
```

→ http://127.0.0.1:8765/newtab.html?mock

## 注意

- 相場データは Yahoo Finance の**非公式**エンドポイントから取得しています。遅延があり（東証は約20分）、仕様変更で取得できなくなる可能性があります。個人利用を前提としており、一般公開する場合は正式なデータ API への切り替えが必要です。
- Yahoo Finance に TOPIX・グロース250・JPX日経400・東証REIT指数そのものが無いため、連動 ETF の値で代用しています（画面に「代用」と表示）。
- 日本10年国債利回りは財務省の日次データのため、前営業日比です。
- NHK の経済ニュース RSS は 2026年8月以降、更新が止まっているようです（最新記事が古い場合は画面に警告を表示します）。既定は Yahoo!ニュースです。
- 祝日（`src/static/holidays.js`）と経済イベント（`src/static/events.js`）は手作業のデータです。2027年末まで収録しているので、それ以降は年1回の更新が必要です。
- 表示内容は投資助言ではありません。

## ファイル構成

```
manifest.json          拡張の定義（Manifest V3）
background.js          Service Worker：定期取得・メッセージ受付
newtab.html / .css     新規タブの画面
src/core/              設定・書式・市場カレンダー・銘柄・ストレージ・ポートフォリオ計算
src/data/              データ取得（providers/yahoo・mof・mock）、ニュース、取得スケジューラ
src/ui/                画面の各パネル
src/static/            祝日・経済イベント・銘柄名辞書（年次更新）
tests/                 単体テスト・スモークテスト・SW 疑似実行
tools/devserver.py     開発用サーバー
docs/DESIGN.md         設計書
legacy/newtab.v1.js    v1 のコード（参考用。読み込まれません）
```

表示する指数や初期ウォッチリストは `src/core/config.js` の `PANELS` / `DEFAULT_WATCH` を編集すると変更できます。
